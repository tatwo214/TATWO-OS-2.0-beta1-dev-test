# TATWO OS 2.0 公測版

> **目前狀態（2026-09-25 起）：公測中。** 本倉庫暫時設為私人，只開放受邀帳號，一般人看不到。倉庫設為私人期間，App 內的「檢查更新」與下方的一行安裝指令暫時無法使用，請見「目前限制」。

## 這是什麼
TATWO OS 是 macOS 上的 AI 工作介面，整合對話、模型引擎與工作流程。這是公測版，功能與相容性仍在驗證中。

## 公測版與開發者私人版的分別
這個倉庫只放**公測版**。開發者自己設備上的**私人版**另外管理，不在這裡。

| | 公測版（本倉庫） | 開發者私人版 |
|---|---|---|
| 版號 | 三段，例如 `v2.0.20` | 四段，例如 `v2.0.19.001` |
| 用途 | 給受邀帳號公測 | 只在開發者自己的設備上測試候選版 |
| 發布位置 | 本倉庫的 Releases | 不在本倉庫，也不對外發布 |
| 原始碼 | 白名單匯出的原始碼快照，不含開發歷史 | 開發中的完整原始碼 |
| 來源 | 私人版在開發者設備上驗收過之後，用同一份 App 原始碼重新打包發出 | — |

私人版的候選版號、開發紀錄、設備與帳號資料都不會出現在本倉庫。本倉庫的每一個版本，都來自已經在開發者設備上驗收過的私人候選版。

## 安裝
倉庫恢復公開後，打開「終端機」，貼上這一行按 Enter（會下載最新 Release、驗證 SHA-256、放進 Applications 並開啟）：

```sh
curl -fsSL https://raw.githubusercontent.com/tatwo214/TATWO-OS-2.0-beta1-dev-test/main/install.sh | bash
```

倉庫設為私人期間，受邀帳號請登入 GitHub，到本倉庫的 Releases 下載最新版的 `TATWO-OS.zip`，解壓後把 `TATWO OS.app` 拖進「應用程式」。

## 目前限制
- **倉庫暫時設為私人**：App 內的「檢查更新」與一行安裝指令目前以不登入的方式讀取本倉庫，所以暫時無法使用。之後會讓受邀帳號可以在 App 內登入後更新，或在整理完成後恢復公開。
- **簽章**：目前的 App 以開發者的 Apple 開發憑證簽名，尚未經過 Apple 公證；第一次開啟時，macOS 可能要求你到系統設定允許開啟。之後會換成正式的發佈憑證。
- 公測版功能與相容性仍在驗證中，請保留備份，不要用公測版處理唯一一份的重要資料。
